# Movie Explorer

Aplikasi web untuk menjelajahi film menggunakan data dari API TMDB.

## Teknologi
- HTML, CSS, JavaScript (Vanilla)
- The Movie Database (TMDB) API

## Fitur
- Browsing film berdasarkan kategori
- Fitur pencarian film
- Detail film (sinopsis, rating, genre, durasi)
- Error handling
